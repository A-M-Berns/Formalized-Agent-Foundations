# Paper errata — Garrabrant, Mayer, Wache, Lang, Eisenstat, Dell, *Factored space models* (arXiv:2412.02579v2)

Defects found in the paper while formalizing it, recorded so that a reader comparing the
Lean against the printed page is not misled. Numbering follows the paper's printed
section-scoped counter (`Definition 4.2`, `Lemma C.3`, …).

| # | Where | Printed | Should read | Found |
|---|---|---|---|---|
| E1 | Lemma C.3, proof of (ii)⟹(i) (§C.1) | "Let `f(x)` be arbitrary if there is no `ω ∈ C` with `X(ω) = x`" | presupposes `Val(Y) ≠ ∅`. With `C = ∅`, `Val(X) ≠ ∅` and `Val(Y) = ∅`, (ii) holds vacuously and no `f : Val(X) → Val(Y)` exists, so the equivalence fails. `derivedOn_iff` carries `[Nonempty β]`; harmless for the paper's random variables (a value space is the codomain of a function out of a nonempty `Ω`) but a genuine hypothesis | spike (2026-08-17) |
| E2 | Definition 4.2 (§4.1) | "finite sets `Ω_i`" | nothing requires `Ω_i ≠ ∅`, so `Ω` may be empty, while later arguments choose points of `Ω` or distributions on it (e.g. Lemma C.20 takes "any strictly positive distribution", Lemma 4.12's ⟸ direction takes `Z = U_i` and needs `Ω_i` to vary). Not an error in any statement so far; the Lean adds the hypothesis where it is used | spike |
| E3 | Lemma C.11, part 3 (§C.3) | "If `P = P_J ⊗ P_{I∖J}`, `Q = Q_J ⊗ Q_{I∖J}`, `supp(P_J) ⊆ supp(Q_J)`, and `P(C) > 0`, then `Q(C) > 0`" | false as printed: take `P = δ_ω`, `Q = δ_{ω_J} ⊗ δ_β` with `β ≠ ω_{I∖J}`, `C = {ω}`. The proof (and the only use, Lemma C.12) has `Q = Q_J ⊗ P_{I∖J}`; `Dist.prob_pos_of_marg_support_subset` states the corrected form with both marginal-support inclusions | stage 2 interface |
| E4 | Lemma C.10, proof (§C.3) | `∏_j((1−λ)P_j(c_j) + λP'_j(c_j)) ≥ ∏_j (1−λ)P_j(c_j) + ∏_j λP'_j(c_j)` | false when `I = ∅` (both products are `1`, so it reads `1 ≥ 2`); the "multiply out and drop the nonnegative mixed terms" argument silently assumes `\|I\| ≥ 1`. The lemma's statement still holds at `I = ∅`. `interp_prob_pos` uses the factorwise bound `λP'_i ≤ (1−λ)P_i + λP'_i` instead, giving `R^λ(C) ≥ λ^{\|I\|} P'(C)` | stage 2 fixer |
| E5 | Lemma 5.3 (§5.2) | "`τ` is bijective" | false on all of `Δ^F(Ω^G)`: two factorizing `P^Ω` differing only in a factor `(v, y)` whose parent configuration `y` has `P^Ω(X_pa(v) = y) = 0` have the same image (chain `a → b`, `P^Ω(X_a = 0) = 1`, any two distributions on the `(b, 1)` factor). The paper's own `τ⁻¹ ∘ τ = id` computation divides by `P^Ω(X_pa(v) = x_pa(v))`. True form: `τ` is well defined into `Δ^*(G)`, surjective with the displayed `τ⁻¹` (built from any CPD family) as right inverse, and a bijection between the *strictly positive* members of the two sets — `factorizesOverDAG_tau`, `tau_tauInv`, `tauPos_bijective`, `tauInv_condCPD_tau` | stage 4 interface |
| E6 | Definition 5.7, part 2 (§5.2.3) | "a family of variables `X = (X_w)_{w∈W}` with `X_w : Ω → Obs`" | each `X_w` maps to its own value space and `Obs = ×_w Val(X_w)` with `O` the joint variable — the reading Proposition 5.8 uses (`IsPerfectMapFSM`) | stage 4 interface |
| E7 | Proposition 5.8, part 1, proof (§B.4) | "`M^G = (Ω, X)` is a perfect map of `P` w.r.t. `X`" argued from Proposition 5.5 alone | a perfect map is by Definition 5.7 also a factored space *model* of `P`, i.e. (Proposition 5.4) `P` must factorize over `G`; the proof never shows this. It follows from `G` being a perfect map (hence an I-map) by the standard "I-map ⟹ factorization" theorem (Koller–Friedman Thm 3.1: chain rule + local Markov independences, which are d-separations), which the formalization proves (`PerfectMap.lean`) | stage 4 interface |
| E8 | §5.2 / Prop 5.5, Prop 5.8 | d-separation is used for arbitrary `V₁, V₂, V₃ ⊆ V` (overlapping, `s = t` allowed) but never defined | Prop 5.5 is true only under the convention that trail endpoints are non-collider vertices — blocked if in `Z`, so the zero-edge trail `v — v` is blocked iff `v ∈ Z` — which the proof of Prop 5.8(2) uses ("the path from `v₂` to itself has zero edges and can only be blocked by itself"). Under the other natural reading (an endpoint with an incoming trail edge treated as a collider) the equivalence fails (memo §2, 649 584 brute-force triples). `dd:dsep` fixes this convention | d-sep sizing memo |
